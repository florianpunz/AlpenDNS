The API token is in the file /var/lib/alpendns/api.token.

API token

Run this on the server to show it:

sudo cat /var/lib/alpendns/api.token

Did you set a different path? Then check token_file under [api] in /etc/alpendns/alpendns.toml.

The path in use is also in the startup log: sudo journalctl -u alpendns -g token_file
